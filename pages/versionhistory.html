website version history

this will be updated whenever a new update to the website is pushed! versions are listed from latest to earliest

  • Jul. 27, 2026: Fixed some color issues and updated the icons to double the resolution. I made a drawing app that has most of the features I'd want out of any drawing software, like changing pen size, a color palette, colorpicker, and a funny image stamp button. It's still missing things like a brush outline, undo/redo, and rectangle & circle tools. Also made a missile launcher, but that isn't given a button because it isn't finished yet.
  • Apr. 29, 2026: I bothered to actually make this website cool and something you could actually have fun with outside of just a simple brag sheet, because those are boring. This one was designed like a webOS, based on the Windows 10 UI and with different pages appearing in windows. Asides from reimplementing all previous features except the blog, I added a link to my playlist and a crude mobile support option (not very good to navigate). Still pretty proud of it. This version was submitted to Hack Club's Flavortown.
  • Sep. 6, 2025: The first version of the website. This one was very basic, having a main page, contacts, projects, and a blog (that I neglected). At least there was a cool navbar.
