hackpad

this is a macropad i made for hack club's hackpad ysws (which was part of blueprint when i made it). i really wanted to get into hardware at that time, but i was way too broke. in comes along this program that just so happens to help provide funding and some parts so that i can actually start. the macropad thing was the easiest when i saw it. my initial concept was to have volume/playlist control buttons, a row for 4key rhythm games, and a screen that would display my current track. everything except the screen made it into the final product. i couldn't figure out linking windows to the microcontroller without some os-side script and goofy slap-together data transfer. plus, kmk REALLY doesn't like updating the screen after the keyboard starts running. actually soldering for the first time was not as bad as i thought it would be, but i definitely burnt some joints. i pretty much forgot about the case too, so the actual macropad is just hanging around on my table and the screen just constantly says "hello world". jclpcb shipped 5 pcbs for like 3 dollars without shipping so i really had a bunch of extras that i gave to my friends and threw at people like frisbees. i'm thinking of getting into hardware again sometime.
