project -

rat.png

an extension i made in the span of a few hours for fun. all it does is replace every single image on the current web page with a picture of a rat i doodled. seriously, that is it. (asides from the extra feature of being able to set your own custom image and turning it on and off). after making my first serious js website for the congressional app challenge, i found how people make chrome extensions and thought it looked easy to get into. the actual hardest part of this was paying the $5 for the chrome web license. this was really just a joke, but it ended up having a few users (mostly because i posted it on the hack club slack).
